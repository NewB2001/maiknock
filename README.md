# 麦麦敲门 MaiKnock

📦 **仓库主页**：<https://github.com/NewB2001/maiknock>　｜　📜 **更新日志**：[CHANGELOG.md](CHANGELOG.md)

> 给 [MaiBot](https://github.com/Mai-with-u/MaiBot) 做的 WebUI 私聊伴侣插件。
> 让麦麦**主动来找你聊天**，让你**一键打招呼**，**由你掌管她的"现在是哪一天"**——把某段时间从她的记忆里藏起来，或直接推进剧情；还能**守护她的小说体说话格式**。

- **版本**：[v0.4.0](CHANGELOG.md)（2026-11-24 已发布）
- **插件 ID**：`maiknock.webui_companion`
- **兼容**：MaiBot 1.3.11 ~ 1.4.x，plugin-sdk 2.15+
- **协议**：MIT

---

## 一、它能做什么

| 功能 | 说明 |
|---|---|
| **F1 主动私聊** | 你沉默够久后，麦麦会在随机的时间点主动开口找你聊；带防打扰（随机冷场区间、禁止时段、每日上限） |
| **F2 剧情时间线** | 四条命令把故事时间往前推、往后拉、或设成某一天，还能附带一段剧情提示词。回退时那段时间会从她的对话记忆里"消失" |
| **F3 手动打招呼** | `/mk hi [话头]` 立刻让麦麦开口，不必等静默计时 |
| **F4 小说体说话格式** | 麦麦的回复固定成三段：【】内心想法 →（动作/环境）→ 直接说话。内心和动作各有开关，缺了让她重说，关了代码直接删。**对所有聊天生效** |
| **F5 消息分段管理** | 回复篇幅可调（四个档位，大致范围不是硬截断）；每条回复的段落之间统一空一行，小说体读起来更连贯 |

五个功能完全独立，可以只用其中一个。

## 二、安装

1. 把整个 `maiknock` 文件夹放到 MaiBot 的 `plugins/` 目录下：

   ```
   MaiBot/
   └── plugins/
       └── maiknock/
           ├── _manifest.json
           ├── plugin.py
           ├── config.toml
           └── ...（其余 .py 文件）
   ```

2. 启动（或重启）MaiBot。

3. 打开 **WebUI → 插件**，找到 **「麦麦敲门 MaiKnock」**，确认开关是 **启用**。

4. 在 WebUI 的 **私聊** 里给麦麦发一条消息（先建立对话）。

5. 敲任意一条 `/mk` 命令就完成了——插件会自动把当前私聊窗口记为「麦麦要主动找的人」（只影响主动找你功能，不用专门绑定）。

> 主动私聊在配置页**默认开启**（当前配置已开启）：冷场 60~90 分钟之间随机挑个时刻麦麦会主动开口，每天最多 5 次，免打扰时段 01:00–08:00。这些都能在 WebUI 插件配置页改。

## 三、配置

在 **WebUI → 插件 → 麦麦敲门 → 配置** 里可视化修改（0.3.1 起配置页已按大白话重新设计，只保留用户用得上的项）。

**插件设置**

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `启用麦麦敲门` | true | 总开关，关掉后全部功能停用 |

**麦麦主动找你聊天**

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `开启主动找你` | true | 打开后，冷场时间一到她就可能主动发消息来找你 |
| `冷场多久之后来找你·最早（分钟）`（`silence_threshold_minutes`） | 60 | 冷场区间的最早值：比如 60 = 至少一小时没说话她才可能来找你；实际时刻在「最早」和「最晚」之间随机挑一个，不会准点出现 |
| `冷场多久之后来找你·最晚（分钟）`（`silence_threshold_max_minutes`） | 90 | 冷场区间的最晚值：如 90 = 最晚一个半小时内一定来找你。设成和「最早」一样大就退回固定时刻 |
| `每天最多主动几次`（`daily_max`） | 5 | 一天之内她最多主动来找你几次 |
| `免打扰时段（麦麦在这段时间内不会找你）` | 01:00~08:00 | 可添加多条；每段是「开始/结束」双联整点下拉（00:00~23:00）。开始==结束 = 该段无效；开始>结束 = 跨天（如 22:00~06:00） |

> 没有固定的「两次最小间隔」——她每次主动找你之后（无论你回没回），冷场计时都会重新开始，要再等满一个随机区间才会找你。
> 随机时刻以 2 分钟为步长（比如抽中 76，就会在第 76 分钟左右来找你）。

**小说体说话格式**

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `启用小说体格式` | true | 回复固定成三段：【】内心 →（动作）→ 直接说话，**对所有聊天生效**。下面的「内心想法」「动作/环境」只有在这项打开时才起作用 |
| `内心想法`（内心【】开关） | true | 只在「启用小说体格式」打开时生效。开=每条回复都带内心想法；关=永远不出现【】内容。**⚠️ 关掉其实更耗 token**：模型容易连动作描写一起漏掉、被插件打回重说（多花一次生成）。适合架空沉浸式私聊这类「不要内心戏」的少数玩法，一般玩家建议保持打开 |
| `动作环境`（动作/环境开关） | true | 只在「启用小说体格式」打开时生效。开=每条回复都带动作描写；关=永远不出现（）内容 |

> 内部机制项（扫描间隔、回读参数、静默判定窗口、内心标记词表、重生上限与文案）自 0.3.1 起不再出现在配置页，代码内置同值默认，行为与旧版完全一致；老 `config.toml` 里残留的键会被忽略，不报错。旧版的 `[style_guard.blocks]` 小节（`inner_enabled`/`action_enabled`）：开关值**仍会被识别并生效**（插件自动接管），在 WebUI 配置页保存一次设置即彻底迁移成 [style_guard] 下的中文开关。

配置保存在插件目录的 `config.toml`，也可以直接改文件（改完热更新）。

**回复篇幅与分段（F5）**

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `回复篇幅`（`[reply_length]` 节） | 简短（60-200字） | 四个档位：简短（60-200字）/ 适中（100-400字）/ 详细（150-600字）/ 自由。**大致范围，不是硬性截断**；字数只算说出口的话，【】（）不算；下限恒为 60。「自由」= 只放开字数，小说体格式、内心/动作开关全都照常遵守 |

> 段落间空行是**插件被动技能**：没有开关、不用配置，所有档位都生效（包括「自由」）——每条回复发出去之前，段与段之间都会被整理成空一行。

## 四、命令表（`/mk`）

在私聊里发送，支持 `@麦麦 /mk ...` 前缀形式。

| 命令 | 作用 |
|---|---|
| `/mk now` | 看麦麦理解中的剧情时间 |
| `/mk add 3d 这三天我们去了海边` | 剧情时间推进 3 天。**强烈建议附带剧情提示词**（见下方说明） |
| `/mk back 10h 夜深之后` | 剧情时间回到 10 小时前——**那段时间会从麦麦记忆里藏起来，且不可恢复**（见下方说明）。强烈建议附带剧情提示词 |
| `/mk set 2026-11-25 09:00 此时你只觉得…` | 把剧情时间直接设为某个时刻。设到过去 = 自动按回退处理（跳过的时间藏起来）。强烈建议附带剧情提示词 |
| `/mk hi 马上过来给我讲讲今天的事` | 让麦麦立刻主动开口。hi 后面直接写想让她做的事，**不用加任何括号**（开不开口由她决定；是否开口插件只在后台悄悄记录，不会往聊天里插话） |

### 剧情时间线（F2）补充说明

> **用这三条命令，请尽量带上剧情提示词！** 麦麦不知道你脑子里设计了什么剧情——你只说"过了三天"而不说这三天发生了什么，她就会**自由脑补**，剧情的掌握权就让出去了。命令 = 时间归你定，提示词 = 剧情也归你定，两者合起来才算真正掌控故事。带了会持续注入给她；不带 = 清掉上一次的提示，让她自由发挥。提示词里不能写具体日期（如"2026-11-25"）——那会穿帮，会被拒绝执行。

**剧情提示词**是 `/mk add`、`/mk set`、`/mk back` 三条命令通用的：命令后面直接跟上你想让她知道的剧情（比如 `/mk add 3d 这三天我们去了海边，还吵了一架`）。

> **set 到过去 = 自动当成 back**：`/mk set` 设的时刻比现在剧情时刻早（比如 set 回 3 天前），插件会自动按回退处理——**跳过的那 3 天会从麦麦的记忆里藏起来**，她不会记得；设到未来就是正常跳跃，她照常记得。

> **⚠️ 回退是「失忆」，不可反悔**：`/mk back`（或 set 到过去）藏起来的时间是**永久消失**的——之后就算用 `/mk add 3d` 把剧情时间推回来，那 3 天的记忆**也不会恢复**。`/mk back 3d` 再 `/mk add 3d` ≠ 什么都没发生，而是「那 3 天她彻底忘了」。想清楚了再回退。

**时长写法**：`3d`（天）、`12h`（小时）、`90m`（分钟）、`30s`（秒）；只写数字按小时算。

**set 的时间写法**：支持四种——`2026-11-25 09:01:02`（带秒）、`2026-11-25 09:01`（只到分）、`2026-11-25`（只到天）、`09:00`（**只给时刻 = 故事当天的该时刻**；回退态下就是故事里的那一天，不是现实的那天）。没写的部分落到整分或当天 00:00:00；"现在是几点几分"的具体感受，交给剧情提示词自由发挥就好。

## 五、原理简述

### 两个 hook（F2 的）

F2 部分向 MaiBot 的 Maisaka 生成器注册两个 **BLOCKING** hook，在同一个回调里改写送进模型的对话：

| Hook | 作用位置 | 改写顺序 |
|---|---|---|
| `maisaka.planner.before_request` | 规划阶段（逐条 item） | relabel（改时间） → 遮蔽（藏对话） → 注入叙事声明 |
| `maisaka.replyer.before_model_request` | 回复阶段（整块 blob） | 遮蔽（藏对话） → relabel（改时间） → 注入叙事声明 |

两侧顺序相反是刻意设计的：planner 用 `meta.timestamp` 判断（与文本无关），replyer 靠块边界的 `[HH:MM:SS]` 判断，必须先遮蔽再改块首时间，否则块边界就找不到了。

### 虚构时间线（F2）

- 落盘状态有六个量：`mode` / `offset_sec` / `boundary_ts` / `hidden_until_ts` / `declaration` / `narrative`（剧情提示词）。
- **隐藏区间**是真实 epoch 上的左开右闭区间 `(boundary_ts, hidden_until_ts]`，描述"哪些真实时刻的消息要藏起来"。
- 回退后，处于隐藏区间的对话会从 planner 的 item 和 replyer 的 blob 里被移除，并被替换成一段**不含绝对日期**的叙事声明（否则麦麦会从声明里读出真实日期，穿帮）。
- 声明是"只送最新一代"：新命令产生新声明时，旧声明退役进历史（仅审计，不再注入给麦麦）。

用户验收口径：**隐藏生效时，麦麦编造一个答案是可以接受的；关键是她不会刻意说出旧答案。**

### 小说体说话格式（F4）

F4 另挂两个 BLOCKING hook：

| Hook | 作用 |
|---|---|
| `maisaka.replyer.before_model_request`（第二个 handler） | 往请求里注入小说体「契约」：告诉模型这条回复必须写成三段 |
| `maisaka.replyer.after_response` | 回复后检查：①（内心：……）自动转【内心：……】→ ②缺块打回重生（上限 1 次，防 token 超支）→ ③按开关删块 |

- 判定按**整条回复**：开关打开时缺块就打回重生一次（尽力保证，非数学保证）；开关关闭时代码直接删，100% 不出现。
- 整条全是括号时有**空正文保护**，不会把回复删成空消息。
- **对所有聊天生效**（0.3.3 起，PM 拍板——生效范围的细分管控留给将来的「麦麦聊天室」插件）。
- 运行时敲 `/mk now` 可以看到格式守卫与时间线的实际生效状态。

### 消息分段管理（F5）

F5 同样挂在 `maisaka.replyer` 的两个位置上：

| Hook | 作用 |
|---|---|
| `maisaka.replyer.before_model_request`（第三个 handler） | 往请求里注入「篇幅契约」：告诉模型这条回复大概要写多少字 |
| `maisaka.replyer.after_response` | 回复后把段与段之间整理成空一行 |

- **功能 A 回复字数配置**：请求发出去之前，往上下文末尾追加一条中文契约（例如「这条回复的篇幅尽量控制在 60 到 200 字之间」）。**软约束，不是硬截断**——硬切会把小说体切碎，所以不切。契约项有固定 `item_id`，同一段对话里重复注入只保留一份；切到「自由」档时旧的契约会被清掉，不会「换个档还留着旧要求」。
- **功能 B 段落间空行**：回复生成后、发出去之前，按「字面上新的一段从哪开始」的规则切段，段间统一补一个空行。段起点随内心/动作开关自动切换——开着内心按 `【` 切、只开动作按 `（` 切、两个都关按句末标点切。**不看语义、不猜内容**，已经是整齐空行的不会被重复加。

## 六、目录结构

```
maiknock/
├── _manifest.json        # 插件清单（名称、版本、能力声明、图标）
├── icon.png              # 插件图标（512×512）
├── config.toml           # 当前配置
├── plugin.py             # 插件本体：hook、命令、配置模型
├── timeline.py           # F2 纯逻辑状态模型（无 IO、可离线单测）
├── style_guard.py        # F4 纯逻辑：契约生成、块扫描、删块；F5 段落空行规整（无 IO、可离线单测）
├── reply_length.py       # F5 纯逻辑：字数档位与篇幅契约（无 IO、可离线单测）
├── date_forms.py         # 日期形态表（声明断言与脱敏共用）
├── matcher.py            # 真实 blob 切块与消息匹配
├── blob_processor.py     # replyer 侧遮蔽 + relabel
├── planner_processor.py  # planner 侧遮蔽 + relabel
├── declaration.py        # 叙事声明生成与注入
├── carriers.py           # relabel 载体白名单
└── tests/                # 单元测试
```

## 七、常见问题

**Q：发了 `/mk hi` 麦麦没反应？**
A：命令本身不进聊天管线（由系统直发），是否开口由麦麦当时的生成决定；插件会在后台悄悄确认她开没开口（只记日志，不往聊天里发消息）。若处于夜间免打扰时段或已到每日上限，不会触发。

**Q：改了配置没生效？**
A：WebUI 配置保存后会热更新；直接改 `config.toml` 也是。若改了字段结构，重启一次插件。

**Q：剧情时间推过头了，怎么回去？**
A：两条路都行——`/mk back 10d` 往回拨 10 天，或者 `/mk set` 直接设回过去某个时刻（会自动按回退处理）。两种方式跳过的时间都会从她的记忆里藏起来。**注意：藏起来就解不开**——回退不是「时光倒流」，被藏的时段不会因为你再 add 回来而恢复，这是刻意的设计（失忆就该像真失忆）。

**Q：升级 MaiBot 后插件报错？**
A：检查兼容范围（1.3.11 ~ 1.4.x）。1.4.8 上 replyer 侧只有一个 blob 路径（`reply_prompt.py`），本插件已适配。
