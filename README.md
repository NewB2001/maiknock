# 麦麦敲门 MaiKnock

📦 **仓库主页**：<https://github.com/NewB2001/maiknock>　｜　📜 **更新日志**：[CHANGELOG.md](CHANGELOG.md)

> 给 [MaiBot](https://github.com/Mai-with-u/MaiBot) 做的 WebUI 私聊伴侣插件。
> 让麦麦**主动来找你聊天**，让你**一键打招呼**，**由你掌管她的"现在是哪一天"**——把某段时间从她的记忆里藏起来，或直接推进剧情；还能**守护她的小说体说话格式**。

- **版本**：[v0.4.0](CHANGELOG.md)（2026-11-24 已发布）
- **插件 ID**：`maiknock.webui_companion`
- **兼容**：MaiBot 1.3.11 ~ 1.4.x，plugin-sdk 2.15+
- **协议**：MIT

---

## 一、它能做什么

| 功能 | 说明 |
|---|---|
| **F1 麦麦找你（你被动）** | 在你不想说话，且原意等的情况下，让麦麦主动找你；支持冷场区间、禁止时段、每日上限 |
| **F3 麦麦找你（你主动）** | 在你既不想等，也不想说话的情况下让麦麦主动找你，可注入旁白 |
| **F2 剧情时间线** | 掌管剧情的时间进度，可注入旁白调整剧情 |
| **F4 小说体说话格式** | 让麦麦的回复固定成三段：内心想法 →动作/环境→ 口头话语。不必再去“身份与人格-表达风格”里约束这一点，而且拥有更强的约束力 |
| **F5 消息分段管理** | 控制麦麦的回复字数（最小字数~最大字数）；更智能的换行（前提是你只启用一个消息框）|

五个功能完全独立，可以只用其中一个。

## 二、玩法示例

在私聊里发送，支持 `@麦麦 /mk ...` 前缀形式。

| 命令 | 作用 |
|---|---|
| `/mk now` | 看麦麦理解中的剧情时间 |
| `/mk add 3d 这三天的地牢里…` | 剧情时间推进 3 天——**玩砸的剧情可以用back命令救回来** |
| `/mk back 10h 夜深之后…` | 剧情时间回到 10 小时前——**那段时间会从麦麦记忆里藏起来，且不可恢复** |
| `/mk set 2026-11-25 09:00 此时你只觉得…` | 把剧情时间直接设为某个时刻——**设置回过去的话视为back，请谨慎使用** |
| `/mk hi 魔物出现在了你的背后…` | 不动剧情时间线的情况下推进剧情——**只写旁白不管时间** |

### 补充说明

> **set 到过去 = 自动当成 back**：`/mk set` 设的时刻比现在剧情时刻早（比如 set 回 3 天前），插件会自动按回退处理——**跳过的那 3 天会从麦麦的记忆里藏起来**，她不会记得；设到未来就是正常跳跃，她照常记得。

> **⚠️ back是「不可反悔的失忆」**：`/mk back`（或 set 到过去）藏起来的时间是**永久消失**的——之后就算用 `/mk add 3d` 把剧情时间推回来，那 3 天的记忆**也不会恢复**。`/mk back 3d` 再 `/mk add 3d` ≠ 什么都没发生，而是「那 3 天她彻底忘了」。想清楚了再回退。

**时长写法**：`3d`（天）、`12h`（小时）、`90m`（分钟）、`30s`（秒）；只写数字按小时算。

**set 的时间写法**：支持四种——`2026-11-25 09:01:02`（带秒）、`2026-11-25 09:01`（只到分）、`2026-11-25`（只到天）、`09:00`（**只给时刻 = 故事当天的该时刻**；回退态下就是故事里的那一天，不是现实的那天）。没写的部分落到整分或当天 00:00:00；"现在是几点几分"的具体感受，交给剧情提示词自由发挥就好。
